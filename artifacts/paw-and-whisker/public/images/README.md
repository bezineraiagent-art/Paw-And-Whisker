# Optional photo slots

Drop real photographs here using these exact filenames. Until a file exists, the site shows a labelled
vector illustration instead (and swaps back automatically if a file fails to load). Only upload photos
you own or have the right to use. Suggested size: about 1200 x 800 px, JPEG, under 300 KB.

| Filename                    | Where it appears                       | Content                                              |
| --------------------------- | -------------------------------------- | ---------------------------------------------------- |
| `home-sofa-night.jpg`       | Home page, "Why it exists" section     | Black cat (Lucky) and brown tabby (Sugar) on a sofa at night |
| `puppy-hub-doorframe.jpg`   | Guides hub (`/guides`)                 | Golden puppy by a doorframe with growth marks        |
| `food-hub-safe-counter.jpg` | Toxic food checker hub                 | Kitchen counter with pet-safe foods                  |
| `vet-black-cat-clinic.jpg`  | Find a vet (`/find-a-vet`)             | Person holding a black cat near a clinic             |

Alt text and captions live in `src/content/slots.ts`; edit them if your photo differs.
